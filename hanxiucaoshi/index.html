常见问题

  • 含羞草闭合是真的吗？
    在数字模拟中是真实的。在现实中，含羞草的闭合是由于细胞液流动导致的，这是一种防御机制。

    您可以直接点击页面上的模拟按钮体验，或通过 GitHub 提交代码贡献新的实验项目。
  • 数据会上传到云端吗？
    不会，所有实验均在您的本地浏览器中运行，数据完全隐私保护。
